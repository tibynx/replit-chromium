# 🌐 Chromium on Replit

Chromium inside a Replit project. Chromium is a free and open-source web browser project, primarily developed and maintained by Google. *(It's basically like Chrome.)*

This repository allows you to run the [Chromium](https://www.chromium.org/chromium-projects/) browser on Replit. It's useful when your school or workplace blocks other applications or domains and you want to quickly look up something.

## Setup
1. Click the "Run on Replit" button below. This will create a new project with the necessary files.

    [![Run on Replit](https://img.shields.io/badge/Run%20on%20Replit-%E2%86%92-f3f2ee?style=for-the-badge&logo=replit&labelColor=faf6f1)](https://replit.com/github/tibynx/chromium-replit)

2. Wait for the environment to set up. This may take a few minutes as it downloads and installs Chromium.

3. Once the setup is complete, click the "Run Project" button on the left sidebar to start the browser.
    * You may see that the "Preview" tab is empty. This is normal, as Chromium will open in a separate window. Open the "VNC" tab to view the browser interface.

> ⓘ **Note:**
> Replit's VNC implementation is very limited, so there will be no sound output!
