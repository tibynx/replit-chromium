# 🌐 Chromium on Replit

Chromium inside a Replit project. Chromium is a free and open-source web browser project, primarily developed and maintained by Google. *(It's basically like Chrome.)*

This repository allows you to run the [Chromium](https://www.chromium.org/chromium-projects/) browser on Replit. It's useful when your school or workplace blocks other applications or domains and you want to quickly look up something.

> ⓘ **Note:**
> Replit's VNC implementation is very limited, so there will be no sound output!
